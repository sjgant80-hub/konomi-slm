KONOMI · sleep

It sleeps, and forgets nothing.

Every night the mind runs a fold-cycle: cluster the day's memories, compress each cluster into one dream — and keep that dream only if recall survives the compression. A dream that would lose a memory is not consolidation, it's forgetting, so the gate refuses it and the raw memories stay. It compresses what is safe and never forgets to save space.
