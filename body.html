KONOMI · the body

One cortex, sized to its box.

The body's cortex reads the machine it's on and sizes the model to the real RAM — the same code runs the small cortex on a laptop and the full cortex on a 512 GB box. The neurons are tiny, so any real machine holds all 127 addresses; only the model needs the big box. The cognition stack — pattern-library, neurons, synapses, sleep, evolution — rides on top, unchanged.
