KONOMI · your brain

Your company's brain,
on your own machines.

Point one command at a folder of your CSVs — sales, churn, credit, operations — and walk away owning a booted mind. Each file becomes an organ only if it predicts held-out rows it never saw; a file with no real signal is refused, with the reason written down. The organs compress to seeds measured in bytes, and think() answers with a tamper-evident receipt — or says "I don't know." No cloud. No rented tokens. No black box.

The whole product, three steps

  1. Clone the engine — MIT, zero dependencies, runs anywhere Node runs: 
    git clone https://github.com/sjgant80-hub/konomi-slm && cd konomi-slm
  2. Drop your CSVs in a folder (optionally name each file's target column): 
    data/churn.csv  data/invoices.csv  data/incidents.csv
data/brain.config.json  →  { "targets": { "churn.csv": "Churned" } }
  3. One command. It grows, gates, cuts, boots — and writes the receipts: 
    node tools/your-brain.mjs data
  ✓ organ churn: held-out AUC 0.87 on 4,931 rows it never saw
  ✗ CUT invoices: held-out AUC 0.51 below gate 0.6 — no verified signal, no organ
think(a held-out case) → VERIFIED (receipt 78729dfe39ec…)
think(junk)            → ABSTAIN

It refuses to pretend

A file with no held-out-provable signal does not become an organ — it is cut, with the reason in the receipts. The embarrassing honesty is the feature: a brain that can say "no signal" is a brain whose "yes" means something.

You own it, byte for byte

Each organ is a readable scorecard compressed to a seed (tens of bytes). The seeds re-grow the brain offline, on your metal, forever — no subscription, no API key, no vendor in the loop.

Receipts on every answer

think() routes to a verified organ and returns a content-hashed receipt, or abstains on out-of-distribution input. The same discipline our whole shelf runs on.

Enterprise scale is the same code

This is the engine under the cortex — the full cognition stack (organs, neurons, synapses, sleep, evolution) boots on a laptop today and sizes up to a 512 GB box unchanged. Board-level cost case on request via the contact channel.
